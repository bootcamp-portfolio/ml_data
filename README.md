# Machine Learning Practice Data

머신러닝 실습에 사용되는 예제 데이터셋을 모아 둔 저장소입니다.

## 데이터 예시
저장소에는 BMI, 농구, 물고기, 과일, 이메일 등 다양한 주제의 CSV 및 NPY 파일과 이미지 자료가 포함되어 있습니다.

## 활용
- 데이터 로딩 및 탐색
- 전처리와 특성 확인
- 머신러닝 모델 학습·평가 실습

## 참고
이 저장소는 데이터 자료 중심입니다. 각 파일의 출처, 사용 조건, 컬럼 의미는 해당 데이터와 수업 자료를 확인해 주세요. 데이터셋에 개인정보나 이용 제한이 포함되어 있는지 확인한 뒤 재배포하세요.
